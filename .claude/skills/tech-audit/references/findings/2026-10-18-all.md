## BUGS (must fix)

- ✔ **Parts/Logic/EngineEvaluator.cs:163-168** — the 300..½-limiter idle clamp runs only when a *figure* gives `idle_rpm` (`ApplyEngine(figures, "idle_rpm", 0) != null`); the specs path takes `Finite(assembly!.IdleRpm, MaxRpm)` (≤ 30 000) as it is.
  - **Why:** commit d8c2121 (2026-10-05 fix D) meant the clamp for every idle; 9a5b4ef added the specs path beside it. A mod block with `"specs": { "idle_rpm": 9000 }` writes `MINIMUM=9000` over a 6500 `LIMITER` (`AcEngineData.cs:136`), moves `RPM_THRESHOLD` (:171) and puts the AI downshift above the upshift (:219). Base packs carry 650–1200, so only mods hit it.
  - **Fix:** apply `Math.Clamp(idle, MinIdleRpm, Math.Max(MinIdleRpm, revsTo * MostIdleOfLimiter))` on both paths (move it out of the `if`), and add the specs case to `OwnPartLogicReviewTests`.
- ✔ **Audio/SoundCues.cs:106** — `Enum.TryParse<AudioBus>(json.Bus, ignoreCase: true, …)` accepts numeric strings (`"7"`, `"-1"`) and `"engine"`; the cue is kept with an undefined bus.
  - **Why:** `AudioHub.Play` (`AudioHub.cs:158`) indexes `_groups[(int)bus]`; from `LoopSlot.Tick` (`AudioHub.Cues.cs:310`) inside the pump's `DispatcherTimer` (`AudioHub.cs:91`, `Tick` :196-232 has no catch round `TickLoops`) the `IndexOutOfRangeException` reaches `DispatcherUnhandledException` every 20 ms while the cue is wanted; `App.xaml.cs` counts ten in thirty seconds as fatal. One bad `sfx/*.json` in any mod. (CWE-20.)
  - **Fix:** `Enum.TryParse(...) && Enum.IsDefined(bus) && bus != AudioBus.Engine`, else the problem line; and guard `Play`/`PlayCue` against a zero group.
- ✔ **Parts/PartRebuilds.cs:121** + **Parts/PartsCatalog.cs:373** — `CheckBecomes` calls `get(target)` with the dictionary's value; Newtonsoft reads `"becomes": { "weld_spiders": null }` as a null value, and `PartsCatalog.Get(string id)` does `_parts.GetValueOrDefault(null)`, which throws `ArgumentNullException`.
  - **Why:** `CheckBecomes` runs inside `PartsCatalog.Load` (:156) with no catch; `CarPartsService.LoadCatalog` (:738-750) catches and the `Lazy` keeps the failure, so every car loses its parts for the session on one mod part's typo (CWE-476).
  - **Fix:** skip null/whitespace targets with a problem line in `CheckBecomes`; make `Get(string? id)` return null for null (the aliases path too).
- **Parts/Logic/DynoSheet.cs:65-67** *(Plausible)* — `BeAverageOf` runs `Mid` over sentinel values: `MaxRpm` −1 (`NoMaxRpm`) with the other bank's 6500 gives 3249.5, so the curve stops at 3250 rpm; `MaxFuelFlow`/`MaxAirFlow` 0 (= no limit) with a bank's limit gives half the fuel.
  - **Why:** a V8 with a head that lacks `max_rpm` (a mod head beside a stock one; a head-mounted carburettor on one bank only), reachable from the workbench; `docs/systems/parts-system.md` says the weakest `max_rpm` is the engine's.
  - **Fix:** merge those three as min-of-present (keep the limit that exists), average the rest; a test with one bank at `NoMaxRpm`.
- ✔ **Services/Assetto Corsa/AcUninstall.cs:48-68** + **App.xaml.cs:176** *(Plausible)* — `--uninstall` waits two minutes for AC (`WaitForAcExit`), then with leftovers logs a warning and returns; `Run` ends in `Environment.Exit(0)` whatever happened, and `installer/Package.wxs:89` runs it with `Return="ignore"`.
  - **Why:** an uninstall started while a race runs (or when `AcProcesses` cannot be queried, read as "running") removes the game while the cars' data, their banks and race.ini stay changed, with no next start to put them back; the originals strand under `AcRestore` (CWE-459).
  - **Fix:** write a result the custom action reads (or exit non-zero and drop `Return="ignore"` for a retry/cancel prompt: "Assetto Corsa is running"), or wait without a limit when leftovers exist; a `ProgressText` row so the wizard says what it is waiting for.
- ✔ **installer/Actions/CustomActions.cs:194-206** *(Plausible)* — `Candidates()` is a lazy iterator; on net472 `Path.Combine(steam, "steamapps", …)` throws `ArgumentException` for a registry `SteamPath`/`InstallPath` with an invalid path char, the exception leaves `FirstOrDefault(IsInstall)` (:74) and is caught at :78.
  - **Why:** every later candidate (the other hive, `libraryfolders.vdf`) is skipped and ACFOLDER stays at the ProgramFiles default, so the player is asked for a folder the installer could have found.
  - **Fix:** build each candidate inside a try (as `SafeExists` does) and `yield` only the ones that form.
