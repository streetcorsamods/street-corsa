## Executive summary

The core is in good shape where it matters most. Every write into the AC install keeps the original first, flushes a manifest and only then changes the file. Restores are idempotent and handled per item, deletes are fenced, the result JSON is capped and matched by context id, the FMOD/D3D interop follows the current Microsoft guidance, and no NaN path to engine.ini or power.lut was found. Severity counts: **9 bugs · 32 stability · 25 security/hardening · 15 duplication (5 drifting) · 11 pattern · 10 performance · 21 clean code · 10 test-gap groups**. One bug happens on a normal path: a first-run AC folder pick breaks every race with parts until a restart. Most of the rest are *Plausible*: they need a hostile or broken mod, a crash at the wrong moment, or an unusual machine.

Top 3 fixes:
1. **`App.xaml.cs:740`**: build `CarDataOverlay` after `StartAsync` has settled the AC folder, or give it a `Func<string>` for the cars path. The first-run folder pick leaves it pointing at the old path.
2. **Screens with `async void Enter` (8)**: an `async void` method never rethrows to its caller, so `SafeNavigate` cannot back out of those screens when `Enter` throws. Return a `Task`, or wrap each whole body. Cruise `Leave` and RaceLoading `ReturnFromRace` can strand the player the same way.
3. **Mod-data edges**: guard `POWER_CURVE` in `AcCarSpecs` the way its siblings do. Also drop null/non-finite entries in the AI prompts and part files, catch `ArgumentException` in `PathNames.TryCombineUnder`, and range-check the unchecked rules figures. Each of these lets one bad mod file cost far more than its own entry.

## POSITIVE PATTERNS

- **Changes to the AC install:** every write keeps the original, then flushes the manifest (SafeFile: temp, `Flush(true)`, rename), then changes the file. `AcInstallGate` plus `Seal()` keeps the crash path from landing between a manifest and its change.
- **Restores and deletes:** restores are idempotent and handled per item, and a failure leaves its entry in a rewritten manifest. Recursive deletes are fenced by `IsSafeSegment` + `CombineUnder`, and clones need suffix, parent and marker, with the marker deleted last.
- **Race result intake:** files capped at 1 MB; Newtonsoft defaults (TypeNameHandling none, MaxDepth 64); type errors quarantined; finite and range checks. Matching on the context id stops a stale file from paying out; apply and save happen in one LiteDB transaction before the archive move. The Lua mode writes the file temp-and-rename and quits only after the write.
- **Engine model:** pack figures are sanitized at one choke point (`EngineEvaluator.Finite`, the dyno capped at 30 000 rpm, `IniText.Set(double)` refusing non-finite values). No NaN/∞ path to engine.ini, drivetrain.ini or power.lut was found, and every number written uses InvariantCulture.
- **Native interop matches the current docs:**
  - every FMOD import is a `LibraryImport` with blittable signatures (FMOD_BOOL as `int`, UTF-8 `byte[]` strings);
  - DSP callbacks are static `[UnmanagedCallersOnly]` function pointers that never throw;
  - the release order is enforced (instances → banks → system);
  - D3D9Ex is created with `Multithreaded | FpuPreserve`, uses `CheckDeviceState`, `SetBackBuffer(null)` before release, Lock/Unlock in finally and a debounced resize, all in one base for 11 viewports;
  - the keyboard hook is a function pointer, always unhooked, with `CallNextHookEx` every time.
- **AI:** one long-lived HttpClient (PooledConnectionLifetime 5 min, ConnectTimeout 5 s) with per-request timeouts and hard byte caps. The API key is DPAPI-protected per user, tied to its provider and address, and never logged. Defaults are all local. Model output is never used as a path, command or type. ComfyUI graphs are limited to core nodes with a forced filename prefix.
- **Mod content is contained per entry:** cycles are bounded (class depth 32, alias hops 8, `requires` loops), part trees are capped at 64 where saves are walked, scripts are read strictly and time-boxed, and `StationGround`/`ShellFile`/`AcdFile` bound every count against the bytes left in the file.
- **Code hygiene:**
  - 0 `Console.WriteLine`, 0 `new …Service(` in VMs, 0 MessageBox outside start-up, 0 sync `Dispatcher.Invoke`, 0 `.Result`/`.Wait()` on the UI thread;
  - XAML has no hex colours or literal font sizes outside Styles, and every DataTemplate is registered;
  - every test that sets a process-wide static is in the Globals collection, and no test touches `C:\GAMES`, %AppData% or Documents.
