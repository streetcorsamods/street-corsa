## Executive summary

The writes into the AC install held up again. The new data.acd move-aside writes its manifest before either rename, every restore step can run twice, and the previous audit's top fix (the overlay reads the AC folder through a `Func<string>`) is in place. The new mod zip import has no path escape: entries are checked at plan time and again at unpack. The previous audit's drifting trios (mod-book loaders, power curves, the Lua race.ini reader) have each stayed single. Severity counts: **10 bugs · 19 stability · 5 security/hardening · 17 duplication (3 drifting) · 11 pattern · 14 performance · 19 clean/XAML · 14 test gaps**. Nothing found here leaves the AC install changed. The bugs that happen on a normal path are: stale AC car data after an install change, and a Mod Manager error banner that never clears. The rest need a failed save, a hostile mod or an odd machine.

Top 3 fixes:
1. **`RaceResultIngestionService.cs:301`**: clear the start mark only after the forfeit settles. Today a failed save voids a cash or pink-slip race the player walked away from, instead of forfeiting it.
2. **Mod import and Mod Manager hardening** (`ModImport.cs`, `ModManager.cs`, `ModIds.cs:25`):
   - Cap `mod.json` and the inflated bytes; don't trust the sizes the zip claims.
   - Reject device names.
   - Use `\z` in the mod-id regex.
   - Sweep `_replaced` leftovers.
   - Move delete and list off the UI thread.
3. **`CarPartsService.ForgetInstall` (:548)**: also clear `_specs`, so a folder switch or an updated car mod is used in the same session.

## BUGS (must fix)

- **Street Corsa/Services/Race/RaceResultIngestionService.cs:301-304** ✔ — `ForfeitCoreAsync` clears the race's start mark in a `finally`, even when `ApplyForfeit` → `ApplyAndSave` throws `RaceNotSavedException` (documented as "can be tried again", `RaceResultProcessor.cs:204`). The retry then finds no mark (`SettleWithoutResultAsync`:317) and voids the race. *Plausible* (the save write must fail).
  - **Why:** the mark is the only proof the mode ran; it is dropped before the forfeit is saved.
  - **Fix:** clear the mark after `SettleWithoutResultAsync` returns normally, not in `finally`. Add a test with a processor that throws `RaceNotSavedException` once.
- **Street Corsa/Services/Race/RaceResultProcessor.Field.cs:74-76** ✔ — each rival is matched by `CarIndex`, then by name, then by `others.ElementAtOrDefault(index - 1)`, and matched entries are never taken out of `others`. One result can settle two rivals while another rival's real result is ignored. *Plausible* (a mod format with a missing or shifted car index).
  - **Fix:** keep a `HashSet` of used entries and skip them in all three lookups.
- **Street Corsa/Services/Parts/CarPartsService.cs:548** ✔ — `ForgetInstall` forgets the sounds and factory builds but not `_specs` (:38, each car's AC data), and `_factoryGear` is only re-cached when `_specs` has the car (:425). After switching the AC folder in Settings, or updating a car mod while the game runs, stance, running gear, `DrivesRear` and the paper's fittings use the old data until restart.
  - **Fix:** `_specs.Clear()` in `ForgetInstall`. Check `_suggestedBuilds` too (it is keyed only on the mod set).
- **Street Corsa/Mods/ModIds.cs:25** ✔ — `^[a-z0-9][a-z0-9_-]{0,39}$`: in .NET, `$` also matches before a final `\n`. So `"mymod\n"` passes, and so does `"car\n"`, which gets past the reserved word. The id becomes a namespace and a folder name with a newline in it.
  - **Fix:** end the pattern with `\z`; add the test case.
- **Street Corsa/Services/Career/EventOpponentService.cs:107** ✔ — `IsRacer` also matches on the local ids alone, so an event naming `my_mod:gino` also takes in `other_mod:gino`. `CrewBook.IsLeader` was written to rule out exactly this. *Plausible*.
  - **Fix:** compare full ids when `named` is qualified; compare local ids only when it is bare (or `ModIds.Resolve` it against the event's mod).
- **[Drifting] Street Corsa/Services/PartShops/ShopScene.cs:128-131** ✔ ↔ `Services/CarLot/WarehouseScene.cs:172-182` — fix 4570cca4 clamped the warehouse camera: finite values only, radius and target height ≤ 200 m, beta ±1.5, room within `ScenePaths.Within`. ## SECURITY / INTEGRITY (should fix)

- **[HARDENING] Street Corsa/Mods/ModImport.cs:136-149, :216-217, :289, :471** — the zip-bomb limits trust each entry's claimed size. The free-space check sums `entry.Length`, `mod.json` is read whole with `ReadToEnd()`, and `ExtractToFile` does not stop at the claimed length (CWE-400). ## POSITIVE PATTERNS

- The data.acd / data-folder move-aside writes its manifest first; each restore step checks what is really there and is idempotent. `DropManifest` empties a held manifest, so a held keep folder never re-restores.
- `CarDataOverlay` and the launcher read the AC folder through a `Func<string>` on every call; the previous audit's top bug is fixed.
- ModImport unpacks into a locked, switched-off staging folder, and checks entries at Plan and again at Install (`IsSafe` + `GetFullPath` prefix). Replaced mods are moved aside and moved back on failure.
- `AiHttp`:
  - one long-lived `SocketsHttpHandler` client with `PooledConnectionLifetime` and a connect timeout, as the current guidance has it;
  - redirects are off, so an API key can't leak through a 3xx;
  - every response body is read with a size cap;
  - LLM answers are capped at 16 KB and the player's line at 300 characters.
- Every FMOD call from the UI thread is counted in through `TryEnterFmod`/`LeaveFmod`. The new COM vtable slots and the 304-byte adapter description match the headers, and a test pins them.
- NaN can't reach engine/setup/suspensions/tyres/aero/electronics ini files: `IniText.GetNumber` drops non-finite values, and `IniText.Set` skips them.
- Part trees are capped at 64 deep everywhere. `PartDefinition` zeroes non-finite masses and slot positions and reports them.
- `NavigationService.EnterAsync` backs out a screen whose entering fails, before or after its first await. RaceLoading moved off `async void Enter`.
- Random injection spread to 9 services; `CarValuation.WorthOrPaid` and `CarSaleService.DealerPays` are shared by the player, rivals and the simulator.
- Installer:
  - the uninstall never follows a junction;
  - data removal is opt-in on every path, never on an upgrade;
  - `smoke.ps1` checks both the keep and the remove round.
